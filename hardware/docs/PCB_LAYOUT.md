# Placement / RF / Mechanical 评审

**HOLD：当前是布局研究，不是完整器件布置。** 原生 PCB 中只有真实板框、4 个安装孔、安装孔规则区和 21 个测试焊盘；所有 IC、连接器矩形是用户绘图层上的占位，不含虚构焊盘。不能执行“从原理图更新 PCB”后就认为布局完成。

## 板框和坐标

- 34.5 × 40.0mm，R2.5，四直线加四圆弧构成闭合 Edge.Cuts。
- 板中心与辅助/网格原点都是 (0,0)。板边界 X=±17.25、Y=±20.0。
- Ø1.4 NPTH 中心 `(±15.05, ±17.8)`，与直边距离 2.2mm。当前孔/板边几何已通过原生DRC；螺钉和定位柱仍需结构审核。
- 孔周围设置内半径0.75mm、外半径1mm的临时环形禁铜/禁线/禁过孔/禁焊盘规则区（每孔四扇段；钻孔本身位于空洞）；**不代表螺钉头或定位柱的最终包络**。
- `placement.json` 存储顶视坐标；底面预览镜像 X。IMU 坐标轴需要实际封装旋转和底面变换后标定，不能把板坐标伪装成已核对的传感器 XYZ。

## 层叠与规则

| 层 | 当前定义 | 放行条件 |
|---|---|---|
| L1 / F.Cu | Signal / RF / Components | 实际 RF 引脚与封装 |
| L2 / In1.Cu | GND 层意图 | 连续地平面，尚未覆铜 |
| L3 / In2.Cu | Power | 电源域和铜皮容量审核 |
| L4 / In3.Cu | Signal | 连续参考面 |
| L5 / In4.Cu | GND 层意图 | 连续地平面，尚未覆铜 |
| L6 / B.Cu | Signal / Components | 背面器件与电池高度审核 |

板文件中的 1.0mm 总厚度只是编辑器占位值，不是指定给板厂的层叠。未填写虚构的介质厚度、Dk、铜厚或阻抗线宽。需要板厂六层参数后计算 RF 50Ω、USB 90Ω 差分、共面间距及阻焊影响，再设置 RF/USB 网络类。

目前普通线 0.15mm、3V3 0.4mm、过孔 0.30/0.15mm；最小线宽 0.10mm、间距 0.15mm 是待板厂确认的起始参数，不是工艺能力承诺。没有用放宽 DRC 的方法处理冲突。VBAT_MODEM 不允许按默认线宽开始布线。

## 空间与高度问题

| 项目 | 当前结果 | 处理 |
|---|---|---|
| SIM8230C 顶面中央 | 官方外形 30×30×2.5mm；左右各仅剩 2.25mm | 真实焊盘、courtyard、RF 口方位仍未知。不能从外形反推焊盘。 |
| 顶边 LCD、GNSS、DIV | 仅分区候选，无具体连接器 | 当前相互距离不证明 RF 隔离；GNSS 与 LCD 的邻近是待决冲突，应结合实际 RF 引脚重排。 |
| 底边 Nano SIM | 13×8mm 的**分区预算**与模块重叠，且超出板边 | 不是卡座尺寸。提供卡座后比较背面位置、增大板框或独立卡座小板；未擅自改变板框。 |
| 背面 ESP32 与 IMU | U1 偏上，U3 中心；电源在下部 | 仅器件本体/区域，没有外围器件 placement；官方引脚附近的去耦布局仍缺。 |
| 电源与测试区 | 已调整测试点，避免与初步 DC/DC 区域直接重叠 | 治具针径、公差、间距与地探针分布仍需确认。 |
| 马达与按键 | 已分开 J6 与按键占位 | 外接马达本体/震动耦合、按键行程空间未知。 |
| 蜂窝电容组 | 2×220µF 等尚未选型/布置 | 电容高度可能冲突电池，不能宣称能装入 12–14mm 整机。 |
| 背面电池叠放 | 电池尺寸、腔体与允许高度未知 | 不能证明 <1.2mm；DCDC 电感/连接器尤其需要避让。 |
| 地通孔与背面重叠 | SIM8230C 跨过几乎所有背面区域 | 官方 ground pad/过孔分布可能撞到背面器件；需双面联动审核。 |

## RF 放行条件

四路原理图均保留 π 调谐网络：并联电容 DNP、串联 0Ω、并联电容 DNP。它们是调谐选件，不是未经测量的匹配结果。ESP32 PICO 已集成内部 RF 匹配，外部预留参考其官方外围图；不套用裸芯片匹配数值。

目前没有任何 RF 铜线、固定线宽、过孔或地缝合阵列。必须先有 SIM8230C V2.04 引脚/射频参考图、四种天线和射频连接器确切料号、PCB 厂层叠；GNSS 是否有源、偏置和 ESD 也需确定。随后才按 MAIN → DIV → GNSS → Wi-Fi 顺序规划，保证连续参考地、最短路径和噪声隔离。无法在本板宽内满足时需要机械调整，不能硬挤。

## Keepout 和 3D

只有安装孔附近的临时规则区已实现。天线、电池腔、FPC 弯折、按键行程、Pogo 底座、扬声器腔、麦克风声孔的边界尚未提供，**尚未创建可制造的对应规则区**。没有用猜测的“电池 keepout”禁止整块底层放件。

尚无 3D 模型或干涉检查结果。预览不是 3D 模型，不证明表壳适配。需要装配 STEP、器件模型和高度公差后完成验证。
